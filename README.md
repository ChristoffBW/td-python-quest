# TD Python Quest

A Duolingo-style game for learning **Python in TouchDesigner**. 13 units, 41 lessons and about 300 exercises, built from the official Derivative documentation (Python Tips, Working with OPs/CHOPs/DATs, Extensions, Storage, the `td`, `tdu`, `TDFunctions` and `TDJSON` modules, and the OP/Par/COMP/DAT/CHOP class references).

No build step and no dependencies: the whole game is `index.html`.

## Play locally

Open `index.html` in a browser.

## Progress

- Saved automatically in the browser (`localStorage`), per device.
- Multiple profiles, XP, streaks, stars, accuracy by exercise type, a 14-day XP chart and review suggestions (open the 📊 button).
- **Download backup** / **Import** moves progress between devices.

## Deploy (GitHub Pages)

Settings → Pages → Deploy from a branch → `main` / root.
